# Team workflow

## Roles

- Farmer experience: harvest intake and decision UX
- Marketplace & partners: buyer and partner flows
- Workflow API: route handlers and state transitions
- Database: schema, migrations, and RLS
- AI integration: assessment adapters and recommendation engine

## Branch conventions

- `feat/farmer-experience`
- `feat/marketplace-partners`
- `feat/workflow-api`
- `feat/database`
- `feat/ai-integration`

## PR guidance

- Open PRs against `main`.
- Keep contracts shared before implementation diverges.
- Review validation, tests, and demo data labeling in each PR.
